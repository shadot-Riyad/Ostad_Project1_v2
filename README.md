# Demo Web Shop Automation (Stage 1: setup + Q1)

Playwright (JavaScript, Page Object Model) tests for https://demowebshop.tricentis.com/

## Setup
```bash
npm install

```


## Run
```bash
npm run test:q1        # Q1 only + Allure report
npm run test:ui        # all UI tests in sequence
npm run test:headed    # watch the browser
npm run report:open    # open Allure report
npm run report:html    # open Playwright HTML report
```
